# V1.4.1 — introduction et réinitialisation

- Nouvelle scène d'accueil dédiée aux nouveaux joueurs : contexte de Valrivière, métier de chargé de mission, manufacture et difficultés territoriales.
- Les anciens utilisateurs conservent leur écran et leurs données; aucune réinitialisation automatique.
- Paramètres : relecture de l'introduction ou remise à zéro après une confirmation explicite.
- Le reset supprime uniquement les 4 clés de données principales; copie d'urgence précédente dans `territoires.reset.backup.v1` (non affichée dans l'app).
- Le cache hors ligne et les sources ne sont pas supprimés. Une exportation JSON préalable reste conseillée.
- Validation : npm check et tests GitHub Actions. La compatibilité réelle ancienne tablette Android reste à valider manuellement.
